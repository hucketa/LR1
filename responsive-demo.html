Приклади медіа-запитів

Mobile First підхід

/* Базові стилі для mobile */
.container {
width: 100%;
padding: 1rem;
}
/* Tablet та більше */
@media (min-width: 481px) {
.container {
padding: 2rem;
}
}
/* Desktop та більше */
@media (min-width: 769px) {
.container {
max-width: 1200px;
margin: 0 auto;
}
}

Адаптивна сітка

/* Mobile: 1 колонка */
.grid {
display: grid;
grid-template-columns: 1fr;
gap: 1rem;
}
/* Tablet: 2 колонки */
@media (min-width: 481px) {
.grid {
grid-template-columns: repeat(2, 1fr);
}
}
/* Desktop: 3 колонки */
@media (min-width: 769px) {
.grid {
grid-template-columns: repeat(3, 1fr);
gap: 2rem;
}
}

Адаптивна типографіка

/* Mobile */
h1 {
font-size: 2rem;
line-height: 1.2;
}
/* Tablet */
@media (min-width: 481px) {
h1 {
font-size: 2.5rem;
}
}
/* Desktop */
@media (min-width: 769px) {
h1 {
font-size: 3rem;
line-height: 1.3;
}
}

Mobile First vs Desktop First

Mobile First ✅

Рекомендовано

Переваги:

  • ✓ Пріоритет мобільним користувачам
  • ✓ Краща продуктивність
  • ✓ Прогресивне покращення

  • ✓ Легше масштабувати

Найкращі практики

1

Viewport Meta Tag

Завжди додавайте viewport meta-тег для коректного масштаб ування

<meta name="viewport" content="width=device-width, initial-scale=1.0">
2

Гнучкі одиниці

Використовуйте відносні одиниці (%, em, rem, vw, vh) замі сть px

width: 90%; padding: 2rem;
3

Breakpoints на контенті

Визначайте breakpoints на основі контенту, а не популярни х пристроїв

@media (min-width: 45em) { ... }
4

Оптимізація зображень

Використовуйте srcset та picture для різних розмірів

<img srcset="..." sizes="...">
5

Touch-friendly

Робіть інтерактивні елементи достатньо великими для дотик у (мінімум 44x44px)

min-height: 44px; min-width: 44px;
6

Тестування

Регулярно тестуйте на реальних пристроях та різних браузе рах

DevTools → Device Toolbar
